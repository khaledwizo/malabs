# نبض — مملكة الأجراس الصامتة (نسخة أندرويد)

لعبة تسلّل وألغاز ثنائية الأبعاد بالعربية. هذا الفرع يحتوي:

- `game/` — مصدر اللعبة (HTML5 Canvas). البناء: `node game/tools/build.js` ← `game/dist/index.html`
- `app/` — غلاف أندرويد (WebView) يعرض اللعبة بملء الشاشة وبالوضع الأفقي، مع اهتزاز وزر رجوع.
- `.github/workflows/nabd-apk.yml` — يبني الـAPK تلقائياً عند كل دفع لهذا الفرع، ويضعه في `apk/nabd.apk`
  (وأيضاً في Artifacts باسم Nabd-APK).

## التثبيت
1. نزّل `apk/nabd.apk` إلى الهاتف وافتحه.
2. اسمح بالتثبيت من مصادر غير معروفة إذا طلب الهاتف.

## قبل تثبيت نسخة أحدث
كل بناء جديد موقَّع بمفتاح جديد، فقد يطلب الهاتف حذف النسخة القديمة أولاً.
احفظ تقدّمك قبل الحذف: الإعدادات ← نقل التقدّم ← «نسخ الرمز»، ثم بعد التثبيت الصق الرمز واضغط «استيراد».
