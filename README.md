# جبهة الرافدين (نسخة أندرويد)

لعبة تصويب تكتيكية ثلاثية الأبعاد في أزقّة بغداد القديمة. هذا الفرع يحتوي:

- `game/` — مصدر اللعبة (three.js) و`game/index.html` المبنية. البناء: `node game/tools/build.mjs`
- `app/` — غلاف أندرويد (WebView) بملء الشاشة وبالوضع الأفقي، مع اهتزاز وزر رجوع.
- `.github/workflows/rafidain-apk.yml` — يبني الـAPK تلقائياً ويضعه في `apk/rafidain.apk`.

القادم: تطبيق السيرفر للعب 2 ضد 2 عبر الإنترنت.
