# جبهة الرافدين (نسخة أندرويد)

لعبة تصويب تكتيكية ثلاثية الأبعاد في أزقّة بغداد القديمة، مع لعب أونلاين 2 ضد 2 عبر هاتف وسيط يدير المباراة.

- `game/` — مصدر اللعبة والسيرفر (three.js). البناء: `node game/tools/build.mjs` ← `index.html` (اللعبة) و`server.html` (السيرفر)
- `app/` — تطبيق اللعبة (WebView بملء الشاشة، أفقي، اهتزاز، زر رجوع).
- `server/` — تطبيق «سيرفر الرافدين»: يشغّل المحاكاة المرجعية للمباراة ويبقى مستيقظاً (خدمة أمامية + قفل المعالج والواي فاي).
- `.github/workflows/rafidain-apk.yml` — يبني التطبيقين ويضعهما في `apk/rafidain.apk` و`apk/rafidain-server.apk`.

## اللعب أونلاين
1. ثبّت «سيرفر الرافدين» على هاتف ثالث، افتحه واتركه على الشاحن — يظهر رمز الغرفة.
2. على هاتفي اللاعبين: اللعبة ← «اللعب أونلاين» ← اكتب الرمز ← اتصال.
3. الاتصال يمرّ عبر وسطاء MQTT عامة (يعمل خلف أي شبكة) ويترقّى تلقائياً إلى اتصال مباشر WebRTC عند الإمكان.
